# Aub_Overlay

Overlay Windows léger permettant d’afficher son MMR Rocket League en temps réel directement en jeu

---

## Fonctionnalités

-  Affichage du MMR uniquement en **Ranked Doubles (2v2)** (à voir pour une prochaine MAJ)
-  Mise à jour automatique toutes les 5 secondes du MMR
-  Système de cache local pour éviter les requêtes inutiles
-  Interface overlay transparente (blur)
-  Toujours au-dessus des autres fenêtres
-  Présence dans la barre des tâches (system tray)
-  Fermeture propre via menu tray
-  Support des comptes Epic Games
